## 📚 Idea/Concepto 
La redundancia de zona en el cloud consiste en replicar datos y aplicaciones en múltiples zonas dentro de una misma región geográfica. Esto permite que los servicios sigan funcionando incluso si una zona completa sufre un fallo crítico. En este contexto, una Zona de Disponibilidad (AZ) no es solo un centro de datos individual, sino un conjunto de uno o más centros de datos con infraestructura independiente. Esta estrategia se utiliza para lograr alta disponibilidad (HA) mediante mecanismos de failover automático entre zonas, aunque introduce consideraciones como mayor latencia de red en comparación con la redundancia local y la necesidad de gestionar la consistencia de datos, generalmente mediante replicación síncrona.
