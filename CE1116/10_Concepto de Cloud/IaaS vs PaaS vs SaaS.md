## 📚 Idea/Concepto 
Las tres abreviaciones representan los principales modelos de servicios en la nube, diferenciados por el nivel de control y responsabilidad entre el proveedor y el usuario. El modelo IaaS (Infrastructure as a Service) es la base, donde el proveedor entrega recursos de computación como servidores, almacenamiento, contenedores y redes, mientras el usuario gestiona sistemas operativos, aplicaciones y datos. El modelo PaaS (Platform as a Service) es un entorno diseñado para desarrolladores, listo para crear, probar y desplegar aplicaciones, donde el proveedor también gestiona el sistema operativo, middleware y runtime, reduciendo la carga operativa del usuario. Finalmente, el SaaS (Software as a Service) está orientado al consumo del usuario final, donde el software se entrega como servicio a través de internet, y el proveedor gestiona casi toda la infraestructura y la aplicación, dejando al usuario un control principalmente administrativo. En estos modelos, a medida que aumenta el nivel de abstracción, disminuye la complejidad de gestión para el usuario, pero también su nivel de control.
