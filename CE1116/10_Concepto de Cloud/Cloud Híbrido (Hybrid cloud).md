## 📚 Idea/Concepto 
El cloud híbrido es una combinación entre dos o más entornos diferentes, por ejemplo, cloud publica y cloud privada, que se integran para operar de manera conjunta. Se caracteriza por permitir mover datos y aplicaciones entre entornos, lo que brinda flexibilidad y portabilidad. Al ser una combinación, puede adoptar las características de los entornos involucrados, permitiendo ampliar sus capacidades sin sustituir las limitaciones físicas del otro entorno. Además, esta integración suele apoyarse en mecanismos de interoperabilidad y gestión unificada que permiten coordinar y estandarizar las operaciones entre ambos entornos, generalmente mediante una capa común (como contenedores o Kubernetes). Esta arquitectura también responde a necesidades como la soberanía de datos y la baja latencia, aunque implica retos adicionales en seguridad y complejidad operativa debido a la integración de múltiples entornos.
