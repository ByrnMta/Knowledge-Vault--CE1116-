## 📚 Idea/Concepto 
En términos generales, el escalamiento es la capacidad de un sistema para ajustar recursos con el fin de satisfacer la demanda de una aplicación. En entornos cloud, este ajuste no solo puede ser manual, sino también automático (elasticidad) en función de métricas en tiempo real. Existen dos formas de llevarlo a cabo: el escalamiento vertical (Scale Up/Down), que consiste en aumentar o reducir la capacidad computacional de un recurso existente, aunque puede implicar reinicios y estar limitado por la capacidad máxima del hardware implicado; y el escalamiento horizontal (Scale Out/In), que busca agregar o eliminar instancias o nodos dentro del sistema para modificar las capacidades que ofrece. Este último suele requerir el uso de un balanceador de carga para distribuir el tráfico entre las instancias, es especialmente adecuado para aplicaciones stateless, y permite una mayor flexibilidad en arquitecturas desacopladas donde los recursos pueden escalar de forma independiente.
