## 📚 Idea/Concepto 
La virtual private cloud (VPC) es la capacidad de la nube pública que permite controlar el entorno de red virtual aislado de forma lógica, es decir, donde se pueden desplegar los recursos de computación de forma segura sobre una infraestructura física compartida. Se puede percibir como una sección aislada dentro de la nube pública, la cual brinda control sobre configuraciones de red (tangos de IP, subredes y reglas de acceso) y permite gestionar elementos de red como routers, firewalls o conexiones VPN, esto con el fin de una mayor seguridad y control para quines utilizan los recursos, además de facilitar el control para integración.
